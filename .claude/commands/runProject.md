# Run Project

Run the Python application in this project.



## Instructions

1. Verify that the Python virtual environment exists at:
   `./venv/bin/python3`

2. If the virtual environment does not exist, stop and report the problem. Do not create a new environment automatically.

3. Start the application using exactly:

```bash
./venv/bin/python3 app.py
```

4. Run the application from the project root directory.

5. Stream the application's stdout and stderr so that I can see the runtime output.

6. If the application exits immediately with an error:

   * Analyze the error.
   * Identify the likely root cause.
   * Do not modify application code automatically.
   * Report the error and suggested next step.

7. If the application starts successfully, report that the application is running and show the relevant startup output.

## Important

Do not change application code, configuration files, dependencies, or the virtual environment as part of this command unless explicitly requested.
